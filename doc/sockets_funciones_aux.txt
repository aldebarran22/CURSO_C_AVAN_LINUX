
Funciones auxiliares de los sockets:
#include <arpa/inet.h>



Little-endian: byte menos significativo primero
Big-endian: bytes mas significativo primero




El orden de red es big-endian. 
Las funciones htonl(), htons(), ntohl() y ntohs() convierten enteros entre el orden de la máquina y el orden de red.

Siglas:
h = host, máquina
n = network, red
s = short, 16 bits
l = long, 32 bits


uint16_t htons(uint16_t hostshort);

Convierte un entero de 16 bits desde el orden de la máquina al orden de red.

Se utiliza principalmente para enviar o configurar puertos:
server_address.sin_port = htons(8080);

Conversiones de maquina a red

---------------------------------------------

uint16_t ntohs(uint16_t netshort);
Convierte un entero de 16 bits desde el orden de red al orden de la máquina

Mostrar el puerto de un cliente:
  unsigned int client_port = (unsigned int)ntohs(client_address.sin_port);
  printf("Puerto del cliente: %u\n", client_port);
  
  De red a maquina
  
---------------------------------------------

uint32_t htonl(uint32_t hostlong);
Convierte un entero de 32 bits desde el orden de la máquina al orden de red.

Se usa  para preparar una  direccion especial:
server_address.sin_addr.s_addr = htonl(INADDR_ANY); 

O transmitir loongitudes  de 32 bits

uint32_t name_length = 15;

uint32_t network_name_length = htonl(name_length);

uint32_t network_name_length = send_all(socket_fd, &network_name_length,  sizeof(network_name_length));
  
  
Del host a la red.

---------------------------------------------------------

uint32_t ntohl(uint32_t netlong);
Convierte un entero de 32 bits desde el orden de red al orden de la máquina.

uint32_t network_name_length;

recv_all(socket_fd, &network_name_length, sizeof(network_name_length));

uint32_t name_length = ntohl(network_name_length);

CONVERSIONES DE DIRECCIONES IP:
Se representan en texto o en binario
Texto:   "192.168.1.20"
Binario: struct in_addr

inet_pton()   Texto a binario
inet_ntop()   Binario a texto


Las cuatro funciones están declaradas en <arpa/inet.h>.

2. Conversión de direcciones IP

Las direcciones IP pueden representarse de dos formas:

Plain Text
Texto: "192.168.1.20"
Binario: struct in_addr

Para convertir entre ambas representaciones se utilizan:

Plain Text
inet_pton() Texto a binario
inet_ntop() Binario a texto


inet_pton()

Convierte una dirección IP desde texto a representación binaria. El resultado queda almacenado en orden de red. Admite AF_INET para IPv4 y AF_INET6 para IPv6.


int inet_pton(
    int address_family,
    const char *source,
    void *destination
);

// Para IP v4
struct sockaddr_in server_address;

memset(
    &server_address,
    0,
    sizeof(server_address)
);


server_address.sin_family = AF_INET;
server_address.sin_port = htons(8080);

int result = inet_pton(
    AF_INET,
    "127.0.0.1",
    &server_address.sin_addr
);

---------------------------------------------------------

inet_ntop()

Convierte una dirección IP desde su representación binaria a texto. Admite direcciones IPv4 e IPv6.

Prototipo:

const char *inet_ntop(
int address_family,
const void *source,
char *destination,
socklen_t destination_size
);

Ejemplo IPv4
char client_ip[INET_ADDRSTRLEN];

if (inet_ntop(
        AF_INET,
        &client_address.sin_addr,
        client_ip,
        sizeof(client_ip)) == NULL) {
    perror("inet_ntop");
    return -1;
}

printf(
    "Dirección IP: %s\n",
    client_ip
);


-------------------------------------------------------------
REGLA:
Antes de enviar un entero:
    host -> network

Después de recibir un entero:
    network -> host

Antes de usar una IP escrita como texto:
    inet_pton()

Antes de mostrar una IP binaria:
    inet_ntop()
    
Texto:
    Se envían directamente sus bytes
    No se aplica htonl() a los caracteres
    Conviene enviar antes su longitud
    Emisor y receptor deben acordar la codificación
